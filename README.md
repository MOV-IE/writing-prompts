# 오늘의 글감

단계별 탭으로 글감을 뽑고, 그 자리에서 바로 써 볼 수 있는 글쓰기 연습 사이트입니다.

**사이트 주소:** https://mov-ie.github.io/writing-prompts/

## 탭 구성

| 단계 | 탭 | 나오는 글감 |
|---|---|---|
| 1 | 물건 심문하기 | 평범한 물건 하나와, 생각을 깊게 만드는 질문 5개 |
| 2 | 기억 발굴하기 | 잊고 있던 어린 시절이나 오래된 기억을 떠올리게 하는 질문 하나 |
| 3 | 첫·끝 문장 잇기 | 이유가 궁금해지는 담백한 첫 문장 또는 끝 문장 하나 |
| 4 | 랜덤 규칙 | 형식·금지·포함·시점·분량 중 서로 다른 세 종류에서 뽑은 규칙 3개 |
| 5 | 두 단어 연결 | 서로 멀리 떨어진 단어 두 개와, 연결점을 암시하는 힌트 한 줄 |

## 사용 방법

1. 위쪽 탭에서 원하는 단계를 고릅니다.
2. 글감이 마음에 들지 않으면 **다른 글감 뽑기**를 누릅니다.
3. 아래 입력 칸에 글을 씁니다. 쓰는 동안 자동으로 임시 저장됩니다(탭마다 따로).
4. 다 쓰면 **보관함에 저장**을 누릅니다. 글감과 함께 날짜별로 보관됩니다.
5. 보관함의 **펼치기**로 전체 글을 보고, **삭제**를 두 번 눌러 지울 수 있습니다.
6. **텍스트 파일로 내려받기**를 누르면 보관함 전체가 `.txt` 파일로 저장됩니다.

## 저장과 개인정보

- 쓴 글과 보관함은 서버가 아니라 **지금 쓰는 기기의 브라우저 안에만** 저장됩니다.
- 다른 사람이 같은 주소로 들어와도 내 글은 보이지 않습니다.
- 기기끼리 동기화되지 않습니다. 휴대폰에서 쓴 글은 컴퓨터에서 보이지 않습니다.
- 브라우저의 방문 기록이나 사이트 데이터를 지우면 보관함도 함께 지워집니다.
- 중요한 글은 **텍스트 파일로 내려받기**로 따로 보관해 두세요.
